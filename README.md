# Pontes Salutis — javni statički preview

Ovo je javni, statički pregled nove strukture weba Udruge Pontes Salutis. Sadrži samo HTML, CSS, JavaScript i pripadajuće vizualne materijale za pregled.

- Razvojna WordPress tema i izvorne datoteke ostaju u privatnom repozitoriju.
- Produkcijski web i staging nisu dio ovog repozitorija.
- Ovo nije deployment na hosting; služi za pregled strukture i vizualnog smjera.
